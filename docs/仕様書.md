# ボラ予報 仕様書

最終更新：2026-11-27

## 1. 目的
株価指数などの「値動きの大きさ（ボラティリティ）」を数営業日先まで予測し、天気予報のように表示する。
上がるか下がるか（方向）は予測しない。用途はポジションサイズの調整・リスク管理の目安。

## 3. 対象銘柄とデータ
- yfinance の日足（始値・高値・安値・終値）、2005年〜
- 日経平均(^N225)、S&P500(^GSPC)、NASDAQ100(^NDX)、フィラデルフィア半導体(^SOX)、ドル円(JPY=X)
- `config.TICKERS` で変更。`data/` に置いたCSV（FRED形式なども可）は自動で対象になる
- リターンは日次対数リターン（%）。実現分散は高値・安値からParkinson推定量で代用

## 4. モデル（models.py）
すべて `fit / one_step / forecast` の共通インターフェース。

| モデル | 概要 | 役割 |
|---|---|---|
| HAR-RV | 日・週・月の実現分散（log）で k 日先の実現分散を直接回帰。終値ベースの水準に scale で補正（scale は直近250日で毎日測り直す） | **天気判定の主モデル**（高値・安値が無い銘柄は GJR-GARCH） |
| GJR-GARCH(1,1) | 正規QML。下落時にボラが上がる非対称性 γ | 比較用 |
| EWMA (λ=0.94) | RiskMetrics型 | 検証の基準（ベンチマーク） |
| GJR-t | 誤差をt分布にしたGJR-GARCH | 比較用 |
| EGARCH(1,1) | 対数分散のモデル（正規QML）。2日目以降は乱数（固定）で期待値を計算 | 比較用 |
| HAR-RV+IV | HAR-RV にVIXの水準（日次分散の対数）を加えたもの。米国株のみ | 比較用（VIXは予報対象ではなく説明変数専用） |
| HIST20 | 過去20日の二乗リターン平均 | 素朴な基準 |

- **外部変数（HAR-X）**：日経平均には前夜の米国株（S&P500）の二乗リターンと、その下落分を加える（`config.EXOG`）。
  対象日より前の日付の米国の値だけを使う（日本の寄り付き前に分かる情報）。GJR-GARCHに足すと直近1年で悪化したため HAR-RV のみに適用（`config.EXOG_MODELS`）。

## 5. 予報の出し方（forecast.py）
| 表示 | 決め方 |
|---|---|
| 天気 | 予想σが過去10年の同モデルのσの何%点か。☀️〜20 / 🌤️〜40 / ⛅〜60 / 🌧️〜80 / ⛈️〜95 / 🌀それ以上 |
| 注意報・警報 | 予報期間中に80%点以上で注意報、95%点以上で警報 |
| その日の値動き ±X% | その日1日の変動が3回に2回は収まる幅。標準化残差の実績分布の68%点 × σ |
| 終値の予想範囲 | 今日の終値から k 日分の累積で約68%の範囲。k日累積の標準化値の実績分位点を使う |
| 大外れライン | 同じく実績分布の95%点 × σ（答え合わせの大外れ判定に使う） |
| 大荒れ確率 | 1日の変動が、その銘柄の普段の1日の標準偏差（過去10年）の2倍を超える確率。標準化残差の実績分布から計算（平年値も併記）。1.5倍・3倍の段階も出す。基準は行ごとにアーカイブへ記録（`big_pct`） |
| 信頼度 | 直近250日の答え合わせの、予想レンジ的中率（理想68%）と大外れ率（理想5%）の理想からのずれ。◎／○／△（`web/data/track.js`） |

- 分位点は正規分布の値（68%→1.0、95%→1.96）より狭くしない（`config.TAIL_FLOOR`）
- 年率換算は参考値として「モデル比較」にのみ表示
- 予報日付は、その市場の営業日（東証=日本の祝日と12/31・1/2・1/3、NYSE=米国の休場日、ドル円=土日のみ。`market_cal.py`）。臨時休場は未対応
- データの鮮度：最終日が「今日の前日以前で最も新しい営業日」より古い銘柄（または先行市場）には警告を出す

## 6. 答え合わせ（archive.py）
- 予報するたびに `results/archive/forecasts.csv` に追記（実予報）
- 直近250営業日は、その日までのデータだけで推定し直した「再現」予報も作って採点（`BACKFILL_DAYS`）
- 突き合わせは「基準日から k 営業日後のデータ行」で行う（祝日でずれない）
- 成績：予想範囲に収まった割合（理想68%）、大外れ率（理想5%）、天気の的中率（毎日「くもり」と言った場合と比較）、大荒れ予報のブライアスキル（平年値比）、予報天気ごとの実際の平均変動

## 7. 検証（backtest.py）
- 直近3年、250営業日ごとに拡大窓で再推定。合否は1日先予測で判定し、2〜5日先も測って日数別に表示（合否には使わない）
- 損失：QLIKE・MSE（代理変数 r²）、95%外れ率（正規 / 実績分布）、EWMAとの Diebold-Mariano 検定（Newey-West, lag5）
- 事前固定の合格基準：主モデルのQLIKEがEWMAより小さい銘柄が2/3以上（`ACCEPT_WIN_RATIO`）
- 試行は `results/backtest_log.csv` に毎回追記

## 8. 画面（web/）
機能ごとにページとファイルを分ける。
| ページ | ファイル | 内容 |
|---|---|---|
| 週間予報 | forecast.html / .js / .css | いまの空模様、5営業日の予報カード、株価チャート（6か月以内はローソク足＋予想範囲）、荒れ具合の推移、モデル比較 |
| 予報の当たり具合 | backtest.html / .js | 検証結果の表と推移グラフ、合否 |
| 答え合わせ | archive.html / .js / .css | 成績表、予報天気ごとの実際、推移、予報の記録（出どころ・何日先で絞り込み） |
| 自己相関 | acf.html | r・|r|・r² の自己相関 |
| 共通 | common.css / common.js / chart.js / pricechart.js | 更新ボタン、データの最新読み込み、SVGグラフ、タップで値表示、期間切り替え（1か月〜全期間） |

- スマホ対応（横スクロール、ホーム画面追加用の manifest とアイコン）
- データは `web/data/*.js`（`window.FORECAST` などの形式）を毎回キャッシュなしで読む
